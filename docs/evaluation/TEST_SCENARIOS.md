# 반복 평가 시나리오

## 전체 평가

1. `/tables`에서 시즌 선택과 순위 변동을 확인한다.
2. `/dashboard/551649643`에서 최근 경기, 그래프, 구단가치를 확인한다.
3. `/dashboard/551649643/squad`에서 최근 11인 포메이션과 선수 모달을 확인한다.
4. 매치 상세에서 양 팀 스쿼드, 팀컬러, MOM, 득점 선수를 확인한다.
5. 선수 상세에서 이미지, 강화 단계, 공격포인트 계산을 확인한다.
6. `/hall-of-fame`과 `/admin`의 접근 흐름을 확인한다.
7. PC·모바일과 다크·라이트 모드를 각각 확인한다.

## 회귀 평가

1. 최근 커밋의 변경 파일과 연결된 화면을 먼저 확인한다.
2. 이전 평가의 Blocker·High 항목을 재현한다.
3. 수정된 화면의 새로고침·직접 URL 접근을 확인한다.
4. `npm run lint`, `npm run build`, `npm run backend:check`를 실행한다.

## 배포 전 점검

1. `npm run build` 성공 여부를 확인한다.
2. Docker 빌드에 필요한 `package-lock.json` 동기화를 확인한다.
3. Nginx·Supervisor·Flask·프론트 포트 구성을 확인한다.
4. NAS 볼륨 경로와 `.env` 주입을 확인한다.
5. HTTPS reverse proxy를 통한 실제 접근을 확인한다.
6. 컨테이너 재시작 후 정적 파일과 런타임 데이터가 유지되는지 확인한다.
