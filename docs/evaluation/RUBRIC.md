# 프로젝트 평가 기준

## 점수

- 5: 출시 수준
- 4: 경미한 개선 필요
- 3: 기능은 작동하지만 명확한 결함 존재
- 2: 주요 흐름에 문제
- 1: 검증 불가 또는 사용 불가
- 0: 기능 부재

## 기획·기능

- 페이지별 역할이 명확한가
- 시즌·순위·채굴량 규칙이 일관적인가
- API 데이터와 화면 표시가 일치하는가
- 빈 데이터와 실패 데이터가 구분되는가

## 디자인·UX

- PC·모바일에서 정보가 잘리지 않는가
- 다크·라이트 모드가 모두 읽히는가
- 테이블·포메이션·모달의 우선순위가 명확한가
- 로딩·오류·빈 상태가 이해 가능한가

## 개발

- 라우팅과 데이터 경계가 안정적인가
- 컴포넌트와 계산 로직이 유지보수 가능한가
- 타입·린트·빌드가 통과하는가
- API 실패와 캐시 만료를 안전하게 처리하는가

## 데이터·보안·운영

- Nexon Open API만 필요한 공식 데이터를 가져오는가
- 시즌 종료 시각 기준으로 데이터가 분리되는가
- 관리자 API가 공개 사용자 흐름과 분리되는가
- `.env`, 세션, 캐시, 로그가 외부에 노출되지 않는가
- Docker와 NAS 볼륨 재시작 후에도 필요한 데이터가 유지되는가

## QA

- 주요 페이지와 매치 상세가 새로고침 후 동작하는가
- PC·모바일 주요 뷰포트가 동작하는가
- 콘솔 오류와 404가 없는가
- 이전 평가에서 해결한 문제가 재발하지 않는가
